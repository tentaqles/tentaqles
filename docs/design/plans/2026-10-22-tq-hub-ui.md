# tq hub web interface redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the `tq hub` page on the approved mockup (dark-first Tentaqles look, sidebar shell, board with drag and drop, new card dialog, card page with timeline and tag editor, decisions inbox, runs and reviews, activity, a connections placeholder, settings) on top of the existing Go server, with every behaviour driven by real server responses and the security model unchanged.

**Architecture:** The web layer stays Go stdlib (`net/http`, `html/template`, `embed`). Task 1 replaces `hub.css` with the mockup's token system (every colour is a token, redefined in both light blocks, so components never branch on theme), rewrites `layout.html` into the sidebar shell with an inline SVG sprite, adds template helpers in `view.go`, rewrites `hub.js` as one module with DOM helpers and registries that later tasks add page sections to, and splits `pages.go` into one file per page so later tasks own disjoint files. New routes register through the existing `extraRoutes` `init()` pattern. Policy for the two new write paths (card edits and settings) lives in `runner.Service` (`UpdateCard`, `UpdateSettings`), never in the web layer; handlers only parse and forward.

**Tech Stack:** Go 1.26.7 standard library (`net/http` method patterns, `html/template`, `embed`, `regexp`), plain ES2017 JavaScript in one file, CSS custom properties; existing packages `internal/hub/{store,runner,activity,web}`.

**Spec:** the approved mockup `docs/design/2026-10-21-tq-hub-ui-mockup.html` (look, structure, copy, colours, type, spacing, icons, animations, both themes, simulated behaviours) and `docs/design/2026-10-21-tq-hub-core-design.md` §9 (decisions), §10 (review page), §11 (web page), §15 (security model); `docs/HUB.md` for the behaviours that must not change. Executors read the mockup in a browser before Tasks 1, 3, 4 and 5.

All paths are relative to the monorepo root `C:\repos\tentaqles\tentaqles`. Go commands run from that root in PowerShell (`go test ./internal/hub/web/ -count=1`).

## Global Constraints

- Standard library only; no new `go.mod` dependency, no JavaScript or CSS library, no build step.
- CSP unchanged: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; form-action 'self'`. No inline `<script>` body, no `on*=` attribute, no `javascript:` URL. The SVG sprite lives in `layout.html`.
- No web fonts and no network asset: the hub works offline. `--sans: "Inter",system-ui,-apple-system,"Segoe UI",Roboto,"Helvetica Neue",Arial,sans-serif`; `--mono: "JetBrains Mono",ui-monospace,"Cascadia Mono","SF Mono",Menlo,Consolas,monospace`. Body `14px/1.5`, the mockup's sizes everywhere else; `--r: 8px`; flat surfaces, hairline borders.
- Status vocabulary `queued running waiting finished failed cancelled over-budget`, coloured exactly as the mockup: queued `p-queue`, running `p-run`, waiting `p-wait` (label "waiting on you"), finished `p-done`, failed `p-fail`, cancelled `p-fail`, over-budget `p-budget` (label "over budget"). Every pill also carries `st-<status>`.
- Every string reaches the page through `html/template`; JavaScript sets data with `textContent` or DOM nodes. The single `innerHTML` in `hub.js` is `fragment()`, which parses HTML this hub rendered through `html/template` (a `#main` refresh or a board tile).
- Path ids are validated with `pathID` (`c-` cards, `r-` runs) before any store call or redirect.
- Human-only actions are enforced in `runner.Service`, never in the web layer alone. Agent-marked callers (`X-TQ-Hub-Agent: 1`, on API and form routes alike) cannot change settings, cannot edit tags outside backlog/todo/other lanes, cannot edit a card's title, body or project folder, and still cannot start, cancel, answer, approve, request changes or mark done.
- Masking at write: tags go through `store.UpdateCard`/`store.AddCard` (already masked); settings values are never stored as caller text, only re-serialised from parsed numbers and booleans (see Task 2).
- No remote shutdown: the settings page explains Ctrl+C in the terminal; there is no stop endpoint.
- Theme: dark is the default; the toggle (top bar, icon only: a sun while dark, labelled "Switch to light mode"; a moon while light, labelled "Switch to dark mode") sets `data-theme` on `<html>` and stores `tq-hub-theme` in `localStorage` inside `try/catch`; with nothing stored the page follows the system.

- Conventional commits; stage explicit paths only (`git add <paths>`, never `-A` or `.`); git identity for this repo is `reach@tentaqles.ai` (check `git config user.email` before the first commit).

## Review Focus

1. **A card title with quotes, angle brackets or `onerror=`** appears in `data-title`, the tile, the toast, the dialog's parent list and the activity timeline. It must stay text everywhere (escaped attributes, `textContent` in JS) and never form a tag or handler. Pinned in Task 3 (`TestBoardEscapesTitleEverywhere`) and Task 1 (`TestHubJSBuildsNodesNotHTML`).
2. **An agent session editing tags on a card a human has just moved into In progress** must be refused (403 `human_only`) with the tags unchanged, while the same edit on a Backlog card succeeds and logs actor `agent`. Pinned in Task 2 (`TestAgentEditsTagsOnlyInPlanningLanes`) and Task 5 (`TestAgentTagEditsFollowLanePolicy`).
3. **The settings form with `2,000,000` tokens, `$15` dollars, blank fields, or a zero** must accept separators and the dollar sign, keep a blank field's current value, and refuse a zero or text without writing any of the other fields. Pinned in Task 2 (`TestUpdateSettingsValidatesBeforeWriting`) and Task 9 (`TestSettingsFormParsesHumanNumbers`, `TestSettingsFormRejectsWithoutPartialWrites`).
4. **The activity window boundary:** an entry from yesterday 23:59 local time is not under "Today"; an unknown `days` or `kind` falls back to Today / All instead of an error. Pinned in Task 8 (`TestActivityWindowAndFilters`).
5. **An over-budget decision whose run row is missing** (a hub decision with a stale or empty run id) still renders with its options and note field, just without the numbers. Pinned in Task 6 (`TestOverBudgetDecisionWithoutRunStillRenders`).

```go
func readAsset(t *testing.T, name string) string {
	t.Helper()
	b, err := assets.ReadFile(name)
	if err != nil {
		t.Fatal(err)
	}
	return string(b)
}

const (
	rootOpen      = ":root{"
	lightAutoOpen = `@media (prefers-color-scheme: light){:root:not([data-theme="dark"]){`
	lightPickOpen = `:root[data-theme="light"]{`
)

// themeInvariant tokens are the same in both themes and are not redefined.
var themeInvariant = map[string]bool{"r": true, "sans": true, "mono": true}

var declRe = regexp.MustCompile(`--([a-z0-9-]+)\s*:\s*([^;]+);`)

// cssBlock is the text between opener and the next closing brace.
func cssBlock(t *testing.T, css, opener string) string {
	t.Helper()
	i := strings.Index(css, opener)
	if i < 0 {
		t.Fatalf("hub.css has no %q", opener)
	}
	rest := css[i+len(opener):]
	j := strings.Index(rest, "}")
	if j < 0 {
		t.Fatalf("%q is not closed", opener)
	}
	return rest[:j]
}

func cssTokens(block string) map[string]string {
	out := map[string]string{}
	for _, m := range declRe.FindAllStringSubmatch(block, -1) {
		out[m[1]] = strings.TrimSpace(m[2])
	}
	return out
}

func TestCSSTokensAreRedefinedInBothLightBlocks(t *testing.T) {
	css := readAsset(t, "static/hub.css")
	root := cssTokens(cssBlock(t, css, rootOpen))
	if len(root) < 36 {
		t.Fatalf(":root defines %d tokens; the mockup's set plus the theme tokens is 40", len(root))
	}
	auto := cssTokens(cssBlock(t, css, lightAutoOpen))
	pick := cssTokens(cssBlock(t, css, lightPickOpen))
	for name := range root {
		if themeInvariant[name] {
			continue
		}
		if _, ok := auto[name]; !ok {
			t.Errorf("the system light block does not redefine --%s", name)
		}
		if _, ok := pick[name]; !ok {
			t.Errorf("the toggle light block does not redefine --%s", name)
		}
	}
	for name, v := range auto {
		if _, ok := root[name]; !ok {
			t.Errorf("--%s is defined for light but not in :root", name)
		}
		if pick[name] != v {
			t.Errorf("--%s differs between the two light blocks: %q vs %q", name, v, pick[name])
		}
	}
}

func hexRGB(t *testing.T, v string) [3]float64 {
	t.Helper()
	v = strings.TrimPrefix(strings.TrimSpace(v), "#")
	if len(v) != 6 {
		t.Fatalf("not a #rrggbb colour: %q", v)
	}
	var c [3]float64
	for i := 0; i < 3; i++ {
		n, err := strconv.ParseUint(v[2*i:2*i+2], 16, 8)
		if err != nil {
			t.Fatal(err)
		}
		c[i] = float64(n) / 255
	}
	return c
}

func luminance(c [3]float64) float64 {
	lin := func(x float64) float64 {
		if x <= 0.03928 {
			return x / 12.92
		}
		return math.Pow((x+0.055)/1.055, 2.4)
	}
	return 0.2126*lin(c[0]) + 0.7152*lin(c[1]) + 0.0722*lin(c[2])
}

func contrast(a, b [3]float64) float64 {
	la, lb := luminance(a), luminance(b)
	if la < lb {
		la, lb = lb, la
	}
	return (la + 0.05) / (lb + 0.05)
}

// TestCSSTextContrast: body text, secondary and tertiary text on every surface, every pill, the
// warm button and the log reach WCAG AA (4.5:1) in both themes. The primary button's white text
// is checked at the gradient's start (4.5:1) and its middle (3:1, the mockup's choice; see the
// plan's note on the gradient).
func TestCSSTextContrast(t *testing.T) {
	css := readAsset(t, "static/hub.css")
	themes := map[string]map[string]string{
		"dark":  cssTokens(cssBlock(t, css, rootOpen)),
		"light": cssTokens(cssBlock(t, css, lightPickOpen)),
	}
	pairs := []struct {
		fg, bg string
		min    float64
	}{
		{"fg", "bg", 4.5}, {"fg", "s1", 4.5}, {"fg", "s2", 4.5}, {"fg", "s3", 4.5},
		{"fg-2", "bg", 4.5}, {"fg-2", "s1", 4.5}, {"fg-2", "s2", 4.5}, {"fg-2", "s3", 4.5},
		{"fg-3", "bg", 4.5}, {"fg-3", "s1", 4.5}, {"fg-3", "s2", 4.5}, {"fg-3", "s3", 4.5}, {"fg-3", "lane-bg", 4.5},
		{"sky", "blue-soft", 4.5}, {"orange-t", "orange-soft", 4.5}, {"teal", "teal-soft", 4.5},
		{"red", "red-soft", 4.5}, {"violet", "violet-soft", 4.5}, {"fg-2", "s3", 4.5},
		{"on-warm", "orange", 4.5}, {"on-mark", "teal", 4.5}, {"on-pri", "blue-d", 4.5}, {"on-pri", "blue", 3},
		{"log-fg", "log-bg", 4.5}, {"log-k", "log-bg", 4.5}, {"log-ok", "log-bg", 4.5},
	}
	for theme, tok := range themes {
		for _, p := range pairs {
			got := contrast(hexRGB(t, tok[p.fg]), hexRGB(t, tok[p.bg]))
			if got < p.min {
				t.Errorf("%s: --%s on --%s is %.2f:1, want %.1f:1", theme, p.fg, p.bg, got, p.min)

		}
	}
}

// TestHubJSBuildsNodesNotHTML: data reaches the page through textContent; the only HTML the
// script parses is fragment(), the hub's own html/template output.
func TestHubJSBuildsNodesNotHTML(t *testing.T) {
	js := readAsset(t, "static/hub.js")
	if n := strings.Count(js, "innerHTML"); n != 1 || !strings.Contains(js, "function fragment(html)") {
		t.Fatalf("hub.js uses innerHTML %d times; only fragment() may", n)
	}
	for _, bad := range []string{"outerHTML", "insertAdjacentHTML", "document.write", "eval(", "new Function"} {
		if strings.Contains(js, bad) {
			t.Errorf("hub.js uses %s", bad)
		}
	}
	for _, want := range []string{`"tq-hub-theme"`, "localStorage", "prefers-color-scheme: light", "Switch to light mode", "Switch to dark mode", "#i-sun", "#i-moon", "EventSource"} {
		if !strings.Contains(js, want) {
			t.Errorf("hub.js lacks %q", want)
		}
	}
	if !regexp.MustCompile(`try\s*\{\s*var v = window\.localStorage\.getItem`).MatchString(js) ||
		!regexp.MustCompile(`try\s*\{\s*window\.localStorage\.setItem`).MatchString(js) {
		t.Error("every localStorage access sits inside try/catch")
	}
	if strings.Contains(js, "X-TQ-Hub-Agent") {
		t.Error("the page never marks itself as an agent")
	}
}
```

```go
import (
```

```go
var (
	tagRe  = regexp.MustCompile(`<([a-zA-Z][a-zA-Z0-9-]*)((?:\s+[^\s=>/]+(?:\s*=\s*(?:"[^"]*"|'[^']*'|[^\s"'>]+))?)*)\s*/?>`)
	attrRe = regexp.MustCompile(`([^\s=>/]+)(?:\s*=\s*(?:"[^"]*"|'[^']*'|[^\s"'>]+))?`)
)

// cspProblems lists inline script bodies, on* handler attributes and javascript: URLs. Under
// script-src 'self' none of them would run, so each is a bug that only shows in a browser. It
// parses tags and attribute names, so escaped text such as a card titled "onerror=" passes.
func cspProblems(body string) []string {
	var out []string
	for _, m := range tagRe.FindAllStringSubmatchIndex(body, -1) {
		name := strings.ToLower(body[m[2]:m[3]])
		hasSrc := false
		if m[4] >= 0 {
			for _, a := range attrRe.FindAllStringSubmatch(body[m[4]:m[5]], -1) {
				attr := strings.ToLower(a[1])
				if strings.HasPrefix(attr, "on") {
					out = append(out, "<"+name+"> carries the inline handler "+attr)
				}
				if attr == "src" {
					hasSrc = true
				}
			}
		}
		if name == "script" && (!hasSrc || !strings.HasPrefix(body[m[1]:], "</script>")) {
			out = append(out, "an inline <script> body")
		}
	}
	if strings.Contains(strings.ToLower(body), "javascript:") {
		out = append(out, "a javascript: URL")
	}
	return out
}

func assertCSPSafe(t *testing.T, path string, body string) {

// between is s from the first from up to and including the next to ("" when from is missing).
// Later tasks use it to look inside one section of a page.
func between(s, from, to string) string {
	i := strings.Index(s, from)
	if i < 0 {
		return ""
	}
	rest := s[i:]
	if j := strings.Index(rest, to); j >= 0 {
		return rest[:j+len(to)]
	}
	return rest
}
```

```go
// laneTitle capitalises the first letter: "in progress" reads "In progress".
func laneTitle(name string) string {
	r, n := utf8.DecodeRuneInString(name)
	if n == 0 {
		return name
	}
	return string(unicode.ToUpper(r)) + name[n:]
}

func words(s string) string { return strings.ReplaceAll(s, "-", " ") }

// optionLabel is a decision option as a button reads it: raise-and-resume → "Raise and resume".
func optionLabel(o string) string { return laneTitle(words(o)) }

// pct is used as a whole percentage of total, 1–100 once anything is used, 0 without a total.
func pct(used, total float64) int {
	if total <= 0 || used <= 0 {
		return 0
	}
	p := int(used / total * 100)
	if p > 100 {
		p = 100
	}
	if p < 1 {
		p = 1
	}
	return p
}

func parseTS(ts string) (time.Time, bool) {
	t, err := time.Parse(time.RFC3339, ts)
	return t, err == nil
}

// clock is a stored time as the page shows it: 15:04 today, "Jan 2 15:04" before; unparseable
// text is shown as it is.
func clock(ts string) string {
	t, ok := parseTS(ts)
	if !ok {
		return ts
	}
	t, n := t.Local(), now().Local()
	if t.Year() == n.Year() && t.YearDay() == n.YearDay() {
		return t.Format("15:04")
	}
	return t.Format("Jan 2 15:04")
}

func ago(ts string) string {
	t, ok := parseTS(ts)
	if !ok {
		return ts
	}
	d := now().Sub(t)
	switch {
	case d < time.Minute:
		return "just now"
	case d < time.Hour:
		return fmt.Sprintf("%d min ago", int(d.Minutes()))
	case d < 48*time.Hour:
		return fmt.Sprintf("%d h ago", int(d.Hours()))
	}
	return fmt.Sprintf("%d days ago", int(d.Hours()/24))
}

// prNum is "PR #9" for a pull request URL, "" for anything else.
func prNum(u string) string {
	p, err := url.Parse(u)
	if err != nil {
		return ""
	}
	parts := strings.Split(strings.Trim(p.Path, "/"), "/")
	if len(parts) >= 2 && parts[len(parts)-2] == "pull" && parts[len(parts)-1] != "" {
		return "PR #" + parts[len(parts)-1]
	}
	return ""
}

// clip is the first line of s, cut to max runes with an ellipsis.
func clip(s string, max int) string {
	l, _, _ := strings.Cut(strings.TrimSpace(s), "\n")
	if r := []rune(l); len(r) > max {
		return string(r[:max]) + "…"
	}
	return l
}

		}

	return kind == store.LaneBacklog || kind == store.LaneTodo || kind == store.LaneOther
```

```js
/* tq hub page script: one module, plain DOM, no framework.
 *
 * CSP is script-src 'self': nothing inline runs, so every behaviour is bound here. The file loads
 * in <head> so the saved theme applies before the first paint; the rest starts on DOMContentLoaded.
 * Text that came from data is always set with textContent. The only HTML parsing is fragment(),
 * which reads HTML this hub rendered through html/template (a #main refresh or a board tile). Every
 * visible change follows a server answer: an API response or an SSE change frame. The page never
 * sends the agent header; the server's same-origin guard covers every write it makes.
 */
(function () {
  "use strict";

  var root = document.documentElement;
  root.classList.add("js");

  /* ---------- theme: dark first, follows the system until the toggle picks one ---------- */
  var THEME_KEY = "tq-hub-theme";
  function storedTheme() {
    try { var v = window.localStorage.getItem(THEME_KEY); return v === "light" || v === "dark" ? v : ""; }
    catch (_) { return ""; } // storage blocked (private window, policy): follow the system
  }
  function storeTheme(v) {
    try { window.localStorage.setItem(THEME_KEY, v); } catch (_) { /* kept for this page only */ }
  }
  function isDark() {
    var t = root.getAttribute("data-theme");
    if (t) return t === "dark";
    return !(window.matchMedia && window.matchMedia("(prefers-color-scheme: light)").matches);
  }
  var savedTheme = storedTheme();
  if (savedTheme) root.setAttribute("data-theme", savedTheme);

  /* ---------- registries: page sections add to these ---------- */
  var starters = [];       // run once, after the DOM is ready
  var mainBinders = [];    // run on the first render and after every #main refresh
  var changeHandlers = []; // fn(change) → true when it handled an SSE change frame itself
  var busyChecks = [];     // fn() → true while a refresh would get in the human's way
  var hub = { ws: "", run: "", nav: "", applySearch: null };

  /* ---------- DOM helpers ---------- */
  function $(sel, from) { return (from || document).querySelector(sel); }
  function $$(sel, from) { return Array.prototype.slice.call((from || document).querySelectorAll(sel)); }
  function el(tag, cls, text) {
    var e = document.createElement(tag);
    if (cls) e.className = cls;
    if (text !== undefined && text !== null) e.textContent = String(text);
    return e;
  }
  function clear(node) { while (node && node.firstChild) node.removeChild(node.firstChild); }
  function on(node, type, fn) { if (node) node.addEventListener(type, fn); }
  function fragment(html) {
    var t = document.createElement("template");
    t.innerHTML = html; // html/template output of this hub's own pages, never data built here
    return t.content;
  }
  function cssq(v) { return window.CSS && CSS.escape ? CSS.escape(String(v)) : String(v).replace(/["\\]/g, "\\$&"); }
  function byData(attr, value, from) { return $("[" + attr + '="' + cssq(value) + '"]', from); }
  function laneTitle(name) { return name ? name.charAt(0).toUpperCase() + name.slice(1) : ""; }
  // typing: the human is editing a form field; a refresh now would throw their input away.
  function typing() {
    var a = document.activeElement;
    return !!(a && /^(TEXTAREA|INPUT|SELECT)$/.test(a.tagName) && a.closest("form"));
  }

  var PILL = { queued: "p-queue", running: "p-run", waiting: "p-wait", finished: "p-done", done: "p-done",
    failed: "p-fail", cancelled: "p-fail", "over-budget": "p-budget" };
  var LABEL = { waiting: "waiting on you", "over-budget": "over budget" };
  function pill(status, label) {
    return el("span", "pill " + (PILL[status] || "p-queue") + " st-" + status, label || LABEL[status] || status);
  }

  /* ---------- toast: built from nodes; actions are [label, fn] pairs ---------- */
  var toastTimer = null;
  function hideToast() {
    var t = $("#toast");
    if (!t) return;
    t.classList.remove("on");
    setTimeout(function () { if (!t.classList.contains("on")) clear(t); }, 250); // no focusable leftovers
  }
  function toast(parts, opts) {
    opts = opts || {};
    var t = $("#toast");
    if (!t) return;
    clear(t);
    parts.forEach(function (p) { t.appendChild(typeof p === "string" ? el("span", null, p) : p); });
    var actions = opts.actions || [];
    actions.forEach(function (a, i) {
      var b = el("button", "btn sm" + (i === 0 ? " warm" : ""), a[0]);
      b.type = "button";
      on(b, "click", function () { hideToast(); a[1](); });
      t.appendChild(b);
    });
    t.classList.add("on");
    clearTimeout(toastTimer);
    toastTimer = setTimeout(hideToast, opts.ms || (actions.length ? 12000 : 3400));
    if (actions.length) $("button", t).focus();
  }

  /* ---------- server calls ---------- */
  function withWS(path) {
    if (!hub.ws) return path;
    return path + (path.indexOf("?") < 0 ? "?" : "&") + "ws=" + encodeURIComponent(hub.ws);
  }
  // api always resolves: {ok, status, data}; data is the JSON body ({} when there is none).
  function api(method, path, body) {
    var opts = { method: method, credentials: "same-origin", headers: { Accept: "application/json" } };
    if (body !== undefined) { opts.headers["Content-Type"] = "application/json"; opts.body = JSON.stringify(body); }
    return fetch(withWS(path), opts).then(function (r) {
      return r.text().then(function (txt) {
        var data;
        try { data = txt ? JSON.parse(txt) : {}; } catch (_) { data = { error: txt }; }
        return { ok: r.ok, status: r.status, data: data || {} };
      });
    }, function () {
      return { ok: false, status: 0, data: { error: "The hub is not reachable. Is tq hub serve still running?" } };
    });
  }
  function errText(res) { return (res.data && res.data.error) || "The hub answered " + res.status + "."; }
  function getHTML(path) {
    return fetch(withWS(path), { credentials: "same-origin" }).then(function (r) {
      if (!r.ok) return { status: r.status, html: null };
      return r.text().then(function (t) { return { status: r.status, html: t }; });
    }, function () { return { status: 0, html: null }; });
  }

  /* ---------- live refresh ---------- */
  var refreshTimer = null, stale = false;
  function busy() {
    if (typing()) return true;
    for (var i = 0; i < busyChecks.length; i++) if (busyChecks[i]()) return true;
    return false;
  }
  function bindMain() { mainBinders.forEach(function (fn) { fn(); }); }
  // refreshMain re-renders #main from the server (?fragment=main), never while the human is busy;
  // a skipped refresh runs once they leave the field. The live log keeps its own node.
  function refreshMain() {
    if (refreshTimer) return;
    refreshTimer = setTimeout(function () {
      refreshTimer = null;
      if (busy()) { stale = true; return; }
      stale = false;
      var u = new URL(location.href);
      u.searchParams.set("fragment", "main");
      u.searchParams.delete("flash");
      fetch(u.toString(), { credentials: "same-origin" })
        .then(function (r) { return r.ok ? r.text() : null; })
        .then(function (html) {
          var m = $("#main");
          if (html === null || !m) return;
          var oldLog = $("#log"), y = window.scrollY;
          clear(m);
          m.appendChild(fragment(html));
          var newLog = $("#log");
          if (oldLog && newLog && oldLog.getAttribute("data-run") === newLog.getAttribute("data-run")) newLog.replaceWith(oldLog);
          window.scrollTo(0, y);
          bindMain();
        }, function () { stale = true; });
    }, 300);
  }
  on(document, "focusout", function () { setTimeout(function () { if (stale) refreshMain(); }, 50); });

  var countTimer = null;
  function refreshWaitingCount() {
    clearTimeout(countTimer);
    countTimer = setTimeout(function () {
      var n = $("#waiting-count");
      if (!n) return;
      api("GET", "/api/waiting").then(function (res) {
        if (!res.ok || !Array.isArray(res.data)) return;
        n.textContent = String(res.data.length);
        n.hidden = res.data.length === 0;
      });
    }, 400);
  }
  function appendLog(text) {
    var pre = $("#log");
    if (!pre || !text) return;
    var stick = pre.scrollTop + pre.clientHeight >= pre.scrollHeight - 8;
    pre.appendChild(document.createTextNode(text));
    if (stick) pre.scrollTop = pre.scrollHeight;
  }
  function connect() {
    if (!window.EventSource) return;
    var p = new URLSearchParams();
    if (hub.ws) p.set("ws", hub.ws);
    var log = $("#log");
    if (hub.run && log) { p.set("run", hub.run); p.set("from", log.getAttribute("data-from") || "0"); }
    var es = new EventSource("/events?" + p.toString());
    es.addEventListener("change", function (e) {
      var c = {};
      try { c = JSON.parse(e.data) || {}; } catch (_) { /* a malformed frame still means "something changed" */ }
      refreshWaitingCount();
      for (var i = 0; i < changeHandlers.length; i++) if (changeHandlers[i](c)) return;
      refreshMain();
    });
    es.addEventListener("log", function (e) {
      try { appendLog(JSON.parse(e.data).text); } catch (_) { /* ignore a malformed frame */ }
    });
  }

  /* ---------- moving a card (board drop and the card page's Move form) ---------- */
  function moveToast(out, meta, lane) {
    if (out.enqueued) toast([pill("queued"), el("span", null, meta.title + ": a run starts on the next tick")]);
    else if (out.cancelled) toast([pill("cancelled"), el("span", null, meta.title + ": the run was cancelled and its lock released")]);
    else if (meta.active && !meta.ready) toast([el("span", null, "Moved to " + laneTitle(lane) + ". Add the agent-ready tag to start a run.")]);
    else toast([el("span", null, "Moved to " + laneTitle(lane) + ".")]);
  }
  // moveCard asks the server to move a card. A live run answers 409: the toast asks before the run
  // is cancelled. done(ok) runs once per server answer; ok false means the caller undoes its preview.
  function moveCard(id, lane, meta, done) {
    meta = meta || {};
    meta.title = meta.title || "The card";
    done = done || function () {};
    var path = "/api/cards/" + encodeURIComponent(id) + "/move";
    api("POST", path, { lane: lane, cancel_run: false }).then(function (res) {
      if (res.ok) { moveToast(res.data, meta, lane); done(true); return; }
      done(false);
      if (res.status === 409 && res.data.code === "run_active") {
        var run = res.data.run || {};
        toast([pill(run.status || "running"), el("span", null, meta.title + " has a " + (run.status || "live") + " run. Moving it cancels the run.")], {
          actions: [
            ["Cancel the run and move", function () {
              api("POST", path, { lane: lane, cancel_run: true }).then(function (r2) {
                if (r2.ok) { moveToast(r2.data, meta, lane); done(true); } else toast([el("span", null, errText(r2))]);
              });
            }],
            ["Keep it running", function () {}]
          ]
        });
        return;
      }
      toast([el("span", null, errText(res))]);
    });
  }
  function bindMoveForms() {
    $$("form[data-move]").forEach(function (f) {
      on(f, "submit", function (e) {
        e.preventDefault();
        var sel = $('[name="lane"]', f);
        moveCard(f.getAttribute("data-card"), sel.value, { title: f.getAttribute("data-title") }, function (ok) { if (ok) refreshMain(); });
      });
```

```go
// MaxConcurrency bounds the concurrency a human can set from the page or the API.
const MaxConcurrency = 16

// Validate reports a budget whose limits are not all positive, finite numbers.
func (b Budget) Validate() error {
	if !b.valid() {
		return fmt.Errorf("budget %s: tokens, usd, minutes and rounds must all be positive numbers", b.String())
	}
	return nil
}

func (s *Store) SetConcurrency(n int) error {
	if n < 1 || n > MaxConcurrency {
		return fmt.Errorf("concurrency %d: use 1 to %d", n, MaxConcurrency)
	}
	if err := s.SetSetting(SettingConcurrency, strconv.Itoa(n)); err != nil {
		return err
	}
	s.Publish(Change{Kind: "settings"})
	return nil
}

// SetDefaultBudget stores the budget re-serialised from the validated struct, never caller text.
func (s *Store) SetDefaultBudget(b Budget) error {
	if err := b.Validate(); err != nil {
		return err
	}
	raw, err := json.Marshal(b)
	if err != nil {
		return err
	}
	if err := s.SetSetting(SettingDefaultBudget, string(raw)); err != nil {
		return err
	}
	s.Publish(Change{Kind: "settings"})
	return nil
}

	if err := s.SetSetting(SettingNotify, strconv.FormatBool(on)); err != nil {
```

```go
	}

// ActivitySince is every entry at or after since, newest first, at most limit (0 → 500). Stored
// times are RFC3339 UTC, so the text comparison is a time comparison.
func (s *Store) ActivitySince(since time.Time, limit int) ([]activity.Entry, error) {
	if limit <= 0 {
		limit = 500
	}
	return scanActivity(s.DB.Query(`SELECT ts, workspace, actor, verb, COALESCE(card_id, ''), COALESCE(run_id, ''), data
		FROM activity WHERE ts >= ? ORDER BY rowid DESC LIMIT ?`, since.UTC().Format(time.RFC3339), limit))
}

func scanActivity(rows *sql.Rows, err error) ([]activity.Entry, error) {
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []activity.Entry
	for rows.Next() {
		var e activity.Entry
		var data string
		if err := rows.Scan(&e.TS, &e.Workspace, &e.Actor, &e.Verb, &e.CardID, &e.RunID, &data); err != nil {
			return nil, err
		}
		_ = json.Unmarshal([]byte(data), &e.Data)
		out = append(out, e)
	}
	return out, rows.Err()
}
```

```go
import (
	"context"

// UpdateCard edits a card's title, body, project folder or tags. An agent session may change the
// tags only, and only on a card in a planning lane (backlog, todo, other): the lanes it may also add
// to and move between. Everything else about a card is the human's (spec §15). Adding agent-ready
// here starts nothing; a run starts when a card enters an active lane.
func (s *Service) UpdateCard(ctx context.Context, id string, u store.CardUpdate) (store.Card, error) {
	if u.Title == nil && u.Body == nil && u.ProjectDir == nil && u.Tags == nil {
		return store.Card{}, errors.New("nothing to update: send a title, body, project folder or tags")
	}
	card, err := s.st.Card(id)
	if err != nil {
		return store.Card{}, err
	}
	actor := s.human()
	if IsAgent(ctx) {
		if u.Title != nil || u.Body != nil || u.ProjectDir != nil {
			return store.Card{}, ErrHumanOnly
		}
		lane, err := s.st.Lane(card.Lane)
		if err != nil {
			return store.Card{}, err
		}
		if !agentLane(lane.Kind) {
			return store.Card{}, ErrHumanOnly
		}
		actor = "agent"
	}
	return s.st.UpdateCard(id, u, actor)
}

// Settings are the workspace's run settings as the page shows them.
type Settings struct {
	Concurrency   int          `json:"concurrency"`
	DefaultBudget store.Budget `json:"default_budget"`
	Notify        bool         `json:"notify"`
}

// SettingsUpdate carries the settings to change; nil fields stay as they are. A budget is
// replaced whole and must be valid.
type SettingsUpdate struct {
	Concurrency   *int          `json:"concurrency,omitempty"`
	DefaultBudget *store.Budget `json:"default_budget,omitempty"`
	Notify        *bool         `json:"notify,omitempty"`
}

func (s *Service) Settings() Settings {
	return Settings{Concurrency: s.st.Concurrency(), DefaultBudget: s.st.DefaultBudget(), Notify: s.st.Notify()}
}

// UpdateSettings is human-only. Every field is validated before any is written, so a refused update
// changes nothing.
func (s *Service) UpdateSettings(ctx context.Context, u SettingsUpdate) (Settings, error) {
	if IsAgent(ctx) {
		return Settings{}, ErrHumanOnly
	}
	if u.Concurrency == nil && u.DefaultBudget == nil && u.Notify == nil {
		return Settings{}, errors.New("nothing to update: send concurrency, default_budget or notify")
	}
	if u.Concurrency != nil && (*u.Concurrency < 1 || *u.Concurrency > store.MaxConcurrency) {
		return Settings{}, errors.New("concurrency: use a whole number from 1 to 16")
	}
	if u.DefaultBudget != nil {
		if err := u.DefaultBudget.Validate(); err != nil {
			return Settings{}, err
		}
	}
	var fields []any
	if u.Concurrency != nil {
		if err := s.st.SetConcurrency(*u.Concurrency); err != nil {
			return Settings{}, err
		}
		fields = append(fields, "concurrency")
	}
	if u.DefaultBudget != nil {
		if err := s.st.SetDefaultBudget(*u.DefaultBudget); err != nil {
			return Settings{}, err
		}
		fields = append(fields, "default_budget")
	}
	if u.Notify != nil {
		if err := s.st.SetNotify(*u.Notify); err != nil {
			return Settings{}, err
		}
		fields = append(fields, "notify")
	}
	_ = s.st.Log(activity.Entry{Actor: s.human(), Verb: activity.VerbSettingsUpdate, Data: map[string]any{"fields": fields}})
	return s.Settings(), nil
}
```

Card anatomy, from the mockup: title link; one status line (a pill and a short text, or the kind and tag chips when nothing is happening); for an active run a dollar-budget bar; one meta line (run id, cost, minutes for an active run; PR link, total cost, card id and the card's own budget otherwise). A pending decision gives the orange edge (`.hot`) and the action on the card: "Open review" for a `result`, an "Approve plan" form plus "Review it" for a `plan-approval` that offers `approve`, "Answer" for anything else. A finished run in a review lane gets "Open review".

```go
package web

import (
	"fmt"
	"net/http"
	"slices"
	"strings"

	"github.com/tentaqles/tentaqles/internal/hub/runner"
	"github.com/tentaqles/tentaqles/internal/hub/store"
)

func init() {
	extraRoutes = append(extraRoutes, func(s *Server) { s.handle("GET /cards/{id}/tile", s.cardTile) })
}

type laneView struct {
	Lane  store.Lane
	Cards []boardCard
}

type boardData struct {
	Lanes []laneView
}

type tileData struct {
	WS   string
	Card boardCard
}

// boardCard is everything one board tile shows; the board and the tile route build it the same way.
type boardCard struct {
	runner.CardView
	LaneKind   string
	Run        *store.Run      // the active run
	Last       *store.Run      // the newest run when none is active
	Decision   *store.Decision // the oldest pending decision: the one to answer first
	PR         string          // the PR link a comment carried (review and done lanes)
	BudgetUSD  float64         // the card's own dollar budget, when its front matter sets one
	OverBudget int             // runs of this card that stopped at a budget
}

func newBoardCard(v runner.CardView, laneKind string, runs []store.Run, pending []store.Decision, pr string, def store.Budget) boardCard {
	b := boardCard{CardView: v, LaneKind: laneKind, PR: pr}
	for i := range runs {
		r := runs[i]
		if r.Status == store.StatusOverBudget {
			b.OverBudget++
		}
		if r.Active() && b.Run == nil {
			b.Run = &r
		}
	}
	if b.Run == nil && len(runs) > 0 {
		r := runs[0] // RunsForCard is newest first
		b.Last = &r
	}
	if n := len(pending); n > 0 {
		d := pending[n-1] // pending decisions are newest first
		b.Decision = &d
	}
	if _, ok := store.FrontMatter(v.Body)["budget"]; ok {
		if bud, err := store.CardBudget(v.Card, def); err == nil {
			b.BudgetUSD = bud.USD
		}
	}
	return b
}

// Status is the one status the tile shows: waiting on you, the active run's, the last run's (not
// in done), over-budget for a done card that hit a budget on the way, or "".
func (b boardCard) Status() string {
	switch {
	case b.Decision != nil:
		return store.StatusWaiting
	case b.Run != nil:
		return b.Run.Status
	case b.Last != nil && b.LaneKind != store.LaneDone:
		return b.Last.Status
	case b.LaneKind == store.LaneDone && b.OverBudget > 0:
		return store.StatusOverBudget
	}
	return ""
}

func (b boardCard) doneOverBudget() bool {
	return b.Decision == nil && b.Run == nil && b.LaneKind == store.LaneDone && b.OverBudget > 0
}

func (b boardCard) PillLabel() string {
	if b.doneOverBudget() {
		if b.OverBudget == 1 {
			return "budget raised once"
		}
		return fmt.Sprintf("budget raised %d times", b.OverBudget)
	}
	return statusLabel(b.Status())
}

func (b boardCard) StatusText() string {
	switch {
	case b.Decision != nil:
		if b.Decision.AskedAt == "" {
			return words(b.Decision.Kind)
		}
		return words(b.Decision.Kind) + ", " + ago(b.Decision.AskedAt)
	case b.Run != nil:
		switch b.Run.Status {
		case store.StatusRunning:
			return fmt.Sprintf("round %d of %d", max(b.Run.Rounds, 1), b.Run.Budget.Rounds)
		case store.StatusQueued:
			if b.Run.Rounds == 0 {
				return "starts when a slot is free"
			}
			return "resumes when a slot is free"
		}
		return "waiting on the gate"
	case b.Last != nil && b.LaneKind != store.LaneDone:
		switch b.Last.Status {
		case store.StatusFinished:
			return fmt.Sprintf("%d rounds, $%.2f", b.Last.Rounds, b.Last.CostUSD)
		case store.StatusOverBudget:
			return "stopped at its budget"
		}
		return clip(b.Last.StopReason, 80)
	}
	return ""
}

func (b boardCard) Pct() int {
	if b.Run == nil {
		return 0
	}
	return pct(b.Run.CostUSD, b.Run.Budget.USD)
}

func (b boardCard) CanApprove() bool {
	return b.Decision != nil && b.Decision.Kind == store.KindPlanApproval && slices.Contains(b.Decision.Options, "approve")
}

func (b boardCard) OpenReview() bool {
	return b.Decision == nil && b.Run == nil && b.Last != nil && b.Last.Status == store.StatusFinished && b.LaneKind == store.LaneReview
}

// tile reads what newBoardCard needs beyond the card view: the runs and, for review and done
// lanes, the PR link.
func tile(svc *runner.Service, v runner.CardView, laneKind string, pending []store.Decision) (boardCard, error) {
	runs, err := svc.Store().RunsForCard(v.ID)
	if err != nil {
		return boardCard{}, err
	}
	pr := ""
	if laneKind == store.LaneReview || laneKind == store.LaneDone {
		pr = runner.PRLink(svc.Store(), v.ID)
	}
	return newBoardCard(v, laneKind, runs, pending, pr, svc.Store().DefaultBudget()), nil
}

func (s *Server) board(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	lanes, err := svc.Store().Lanes()
	if err != nil {
		s.fail(w, r, err)
		return
	}
	views, err := svc.List(s.reqCtx(r), store.CardFilter{}, false)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	pending, err := svc.Store().PendingDecisions()
	if err != nil {
		s.fail(w, r, err)
		return
	}
	byCard := map[string][]store.Decision{}
	for _, d := range pending {
		byCard[d.CardID] = append(byCard[d.CardID], d)
	}
	data := boardData{}
	for _, l := range lanes {
		lv := laneView{Lane: l}
		for _, v := range views {
			if !strings.EqualFold(v.Lane, l.Name) {
				continue
			}
			bc, err := tile(svc, v, l.Kind, byCard[v.ID])
			if err != nil {
				s.fail(w, r, err)
				return
			}
			lv.Cards = append(lv.Cards, bc)
		}
		data.Lanes = append(data.Lanes, lv)
	}
	p := s.basePage(r, "Board", ws)
	p.Nav = "board"
	p.Data = data
	s.render(w, r, "board", p)
}

// cardTile renders one tile: the board's live refresh re-reads a card after an SSE change.
func (s *Server) cardTile(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	id, ok := s.pathID(w, r, "id", "c")
	if !ok {
		return
	}
	d, err := svc.Show(s.reqCtx(r), id)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	lane, err := svc.Store().Lane(d.Lane)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	var pending []store.Decision
	for _, dec := range d.Decisions {
		if dec.Status == store.DecisionPending {
			pending = append(pending, dec)
		}
	}
	bc, err := tile(svc, d.CardView, lane.Kind, pending)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	w.Header().Set("Content-Type", "text/html; charset=utf-8")
	if err := s.tpl.ExecuteTemplate(w, "board-card", tileData{WS: ws, Card: bc}); err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError)
	}
}
```

```js
  var drag = null;       // { card, from, next } while a card is dragged
  var slot = el("div", "slot");
  var heldTiles = {};    // tile refreshes that arrived mid-drag
  var tileTimers = {};
  var quietUntil = {};   // card id → until when a status change does not toast (the move already did)

  function laneOf(node) { return node && node.closest ? node.closest(".lane[data-lane]") : null; }
  function cardsIn(lane) { return $$(".card[data-card]", lane); }
  function laneCounts() {
    $$(".lane[data-lane]").forEach(function (lane) {
      var n = cardsIn(lane).length, c = $("header .c", lane), empty = $(".empty", lane);
      if (c) c.textContent = String(n);
      if (empty) empty.hidden = n > 0;
    });
  }
  function settle(card) {
    card.classList.remove("settle");
    void card.offsetWidth; // restart the animation
    card.classList.add("settle");
    setTimeout(function () { card.classList.remove("settle"); }, 400);
  }
  function placeSlot(lane, y) {
    var after = null;
    cardsIn(lane).some(function (c) {
      if (drag && c === drag.card) return false;
      var r = c.getBoundingClientRect();
      if (y < r.top + r.height / 2) { after = c; return true; }
      return false;
    });
    if (after) lane.insertBefore(slot, after); else lane.appendChild(slot);
    slot.classList.add("show");
  }
  function endDrag() {
    if (!drag) return;
    drag.card.classList.remove("dragging");
    slot.classList.remove("show");
    if (slot.parentNode) slot.parentNode.removeChild(slot);
    $$(".lane.over").forEach(function (l) { l.classList.remove("over"); });
    drag = null;
    var ids = Object.keys(heldTiles);
    heldTiles = {};
    ids.forEach(refreshTile);
  }
  function statusToast(card) {
    var st = card.getAttribute("data-status");
```

```go
// splitTags reads a comma-separated tag field; the store trims, dedupes and masks.
func splitTags(s string) []string {
	out := []string{}
	for _, t := range strings.Split(s, ",") {
		if t = strings.TrimSpace(t); t != "" {
			out = append(out, t)
		}
	}
	return out
}
```

```js
  // removes the last. onEdit(tags) runs after each change the human makes; set() does not call it.
  function wireTagbox(box, onEdit) {
    var input = $("[data-tag-input]", box);
    function changed() { if (onEdit) onEdit(tagsOf(box)); }
    function chip(name) {
      var t = el("span", "tag" + (name === "agent-ready" ? " ready" : ""), name);
      t.setAttribute("data-tag", name);
      var x = el("button", "x", "×");
      x.type = "button";
      x.setAttribute("aria-label", "Remove tag " + name);
      t.appendChild(x);
      return t;
    }
    function add(raw) {
      var v = String(raw).replace(/,/g, "").trim();
      if (!v || tagsOf(box).indexOf(v) >= 0) return false;
      box.insertBefore(chip(v), input);
      return true;
    }

      if (e.target === box && input) input.focus();
```

```go
package web

import (
	"fmt"
	"sort"

	"github.com/tentaqles/tentaqles/internal/hub/store"
)

// tlItem is one line of the card page's timeline, built only from rows the hub holds: the card's
// runs with their round log, and its decisions.
type tlItem struct {
	When   string // RFC3339; the list is sorted by it
	Class  string // ok | r (in flight) | w (asked) | x (failed, cancelled, over budget) | ""
	Text   string
	Code   string // a machine value shown in monospace after the text
	Detail string // shown after the time
}

const timelineMax = 60

func timeline(runs []store.Run, decisions []store.Decision) []tlItem {
	var out []tlItem
	for _, r := range runs {
		out = append(out, tlItem{When: r.QueuedAt, Text: "Run queued (" + r.OnRamp + ")", Code: r.ID})
		for _, rr := range r.RoundLog {
			it := tlItem{When: rr.StartedAt, Class: "ok", Text: fmt.Sprintf("Round %d", rr.N)}
			if rr.Outcome != "" {
				it.Text += ": " + words(rr.Outcome)
			}
			if rr.ExitCode != 0 {
				it.Class = "x"
			}
			cost := fmt.Sprintf("$%.2f", rr.CostUSD)
			if rr.CostUnknown {
				cost = "cost unknown"
			}
			it.Detail = fmt.Sprintf("%s · %.0f s", cost, rr.Seconds)
			out = append(out, it)
		}
		if r.Status == store.StatusRunning {
			out = append(out, tlItem{When: r.UpdatedAt, Class: "r", Text: "A round is running", Detail: fmt.Sprintf("$%.2f so far", r.CostUSD)})
		}
		if r.EndedAt != "" {
			it := tlItem{When: r.EndedAt, Class: "x", Text: "Run " + statusLabel(r.Status), Detail: clip(r.StopReason, 120)}
			if r.Status == store.StatusFinished {
				it.Class = "ok"
			}
			out = append(out, it)
		}
	}
	for _, d := range decisions {
		kind := laneTitle(words(d.Kind))
		out = append(out, tlItem{When: d.AskedAt, Class: "w", Text: kind + " asked", Code: d.ID})
		if d.Status == store.DecisionAnswered {
			out = append(out, tlItem{When: d.AnsweredAt, Class: "ok", Text: kind + " answered: " + d.Choice, Detail: d.Actor})
		}
	}
	sort.SliceStable(out, func(i, j int) bool { return tsBefore(out[i].When, out[j].When) })
	if len(out) > timelineMax {
		out = out[len(out)-timelineMax:]
	}
	return out
}

// tsBefore orders RFC3339 times (any offset); a missing or unreadable time sorts last.
func tsBefore(a, b string) bool {
	ta, oka := parseTS(a)
	tb, okb := parseTS(b)
	switch {
	case oka && okb:
		return ta.Before(tb)
	case oka:
		return true
	}
	return false
}
```

```go
type cardData struct {
	runner.CardDetail
	Lanes        []store.Lane
	LaneKind     string
	Active       *store.Run
	Run          *store.Run // the facts panel: the active run, else the newest

func (s *Server) cardPage(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	id, ok := s.pathID(w, r, "id", "c")
	if !ok {
		return
	}
	d, err := svc.Show(s.reqCtx(r), id)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	lanes, _ := svc.Store().Lanes()
	data := cardData{CardDetail: d, Lanes: lanes, GateURL: svc.GateURL(), Timeline: timeline(d.Runs, d.Decisions)}
	for _, l := range lanes {
		if strings.EqualFold(l.Name, d.Lane) {
			data.LaneKind = l.Kind
		}
	}
	for i := range d.Runs {
		if d.Runs[i].Active() {
			run := d.Runs[i]
			data.Active = &run
			break
		}
	}
	if data.Active != nil {
		data.Run = data.Active
		data.LogTail, data.LogSize = tailFile(data.Active.LogPath, 16<<10)
	} else if len(d.Runs) > 0 {
		run := d.Runs[0]
		data.Run = &run
	}
	for _, dec := range d.Decisions {
		if dec.Status == store.DecisionPending {
			data.PendingItems = append(data.PendingItems, newDecisionItem(svc, ws, d.Card, dec))
		} else {
			data.Answered = append(data.Answered, dec)
		}
	}
	if _, ok := svc.PendingResult(d.ID); ok {
		data.ReviewReady = true
	}
	for _, run := range d.Runs {
		if run.Status == store.StatusFinished {
			data.ReviewReady = true
		}
	}
	p := s.basePage(r, d.Title, ws)
	p.Nav = "board"
	if data.Active != nil {
		p.RunID = data.Active.ID
	}
	p.Data = data
	s.render(w, r, "card", p)
}

// formTags replaces the card's tags with the form's list plus anything typed into "add". The
// runner decides whether the caller may (an agent only on a card in a planning lane).
func (s *Server) formTags(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	id, ok := s.pathID(w, r, "id", "c")
	if !ok {
		return
	}
	tags := append(splitTags(r.FormValue("tags")), splitTags(r.FormValue("add"))...)
	if _, err := svc.UpdateCard(s.reqCtx(r), id, store.CardUpdate{Tags: &tags}); err != nil {
		s.fail(w, r, err)
		return
	}
	s.redirect(w, r, flashURL(ws, id, "tags-saved"))
}

type updateRequest struct {
	Title      *string   `json:"title,omitempty"`
	Body       *string   `json:"body,omitempty"`
	ProjectDir *string   `json:"project_dir,omitempty"`
	Tags       *[]string `json:"tags,omitempty"`
}

func (s *Server) apiUpdate(w http.ResponseWriter, r *http.Request) {
	svc, _, ok := s.service(w, r)
	if !ok {
		return
	}
	id, ok := s.pathID(w, r, "id", "c")
	if !ok {
		return
	}
	var req updateRequest
	if err := decode(r, &req); err != nil {
		s.fail(w, r, errors.Join(errors.New("the body must be a JSON object"), err))
		return
	}
	c, err := svc.UpdateCard(s.reqCtx(r), id, store.CardUpdate{Title: req.Title, Body: req.Body, ProjectDir: req.ProjectDir, Tags: req.Tags})
	if err != nil {
		s.fail(w, r, err)
		return
	}
	writeJSON(w, 200, c)
}
```

```js
  /* ---------- card page: tags and comments ---------- */
  function clockNow() { var d = new Date(); return ("0" + d.getHours()).slice(-2) + ":" + ("0" + d.getMinutes()).slice(-2); }
  function bindTags() {
    var form = $("form[data-tags-card]");
    if (!form) return;
    var id = form.getAttribute("data-tags-card"), hidden = $('input[name="tags"]', form);
    var tb = wireTagbox($("[data-tagbox]", form), function (tags) {
      var before = hidden.value;
      hidden.value = tags.join(",");
      api("POST", "/api/cards/" + encodeURIComponent(id), { tags: tags }).then(function (res) {
        if (!res.ok) {
          hidden.value = before;
          tb.set(before ? before.split(",") : []);
          toast([el("span", null, errText(res))]);
          return;
        }
        var saved = res.data.tags || [];
        hidden.value = saved.join(",");
        tb.set(saved); // the stored, masked spelling wins
        toast([el("span", null, "Tags saved.")]);
      });
    });
    on(form, "submit", function (e) { e.preventDefault(); tb.flush(); });
  }
  function appendComment(c) {
    var list = $("#comments");
    if (!list) return;
    var none = $("#no-comments");
    if (none) none.remove();
    var one = el("div", "one new"), who = el("div", "who");
    who.appendChild(el("b", null, c.author));
    who.appendChild(el("span", "k", c.author_kind));
    who.appendChild(el("span", null, clockNow()));
    one.appendChild(who);
    one.appendChild(el("div", "txt", c.body)); // plain text until the next refresh renders the markdown
    list.appendChild(one);
  }
  function bindComposer() {
    var form = $("form[data-comment-card]");
    if (!form) return;
    var id = form.getAttribute("data-comment-card"), ta = $("textarea", form), btn = $('button[type="submit"]', form);
    function post() {
      var body = ta.value.trim();
      if (!body) { ta.focus(); return; }
      btn.disabled = true;
      api("POST", "/api/cards/" + encodeURIComponent(id) + "/comments", { body: body }).then(function (res) {
        btn.disabled = false;
        if (!res.ok) { toast([el("span", null, errText(res))]); return; }
        appendComment(res.data);
        ta.value = "";
        toast([el("span", null, "Comment posted and masked for secrets.")]);
      });
    }
    on(form, "submit", function (e) { e.preventDefault(); post(); });
    on(ta, "keydown", function (e) { if ((e.ctrlKey || e.metaKey) && e.key === "Enter") { e.preventDefault(); post(); } });
    on($("[data-clear]", form), "click", function (e) { e.preventDefault(); ta.value = ""; ta.focus(); });
  }
  mainBinders.push(bindTags, bindComposer);
```

```go
package web

import (
	"net/http"
	"slices"
	"sort"

	"github.com/tentaqles/tentaqles/internal/hub/runner"
	"github.com/tentaqles/tentaqles/internal/hub/store"
)

// decisionItem is one decision as the inbox and the card page show it.
type decisionItem struct {
	Workspace  string
	Card       store.Card
	Decision   store.Decision
	Run        *store.Run // the decision's run, when the row still exists
	OverBudget bool       // a hub budget stop: the page shows the run's numbers
}

func newDecisionItem(svc *runner.Service, ws string, card store.Card, d store.Decision) decisionItem {
	it := decisionItem{Workspace: ws, Card: card, Decision: d,
		OverBudget: d.Kind == store.KindPermission && slices.Contains(d.Options, "raise-and-resume")}
	if d.RunID != "" {
		if run, err := svc.Store().Run(d.RunID); err == nil {
			it.Run = &run
		}
	}
	return it
}

// waitingItems gathers pending decisions across the available workspaces; an unavailable one is
// never opened, so it is skipped.
func (s *Server) waitingItems(r *http.Request, only string) []runner.WaitingItem {
	items := []runner.WaitingItem{}
	for _, info := range s.opts.Backend.Workspaces() {
		if !info.Available || (only != "" && info.Name != only) {
			continue
		}
		svc, err := s.opts.Backend.Service(info.Name)
		if err != nil {
			continue
		}
		got, err := svc.Waiting(s.reqCtx(r))
		if err != nil {
			continue
		}
		items = append(items, got...)
	}
	sort.SliceStable(items, func(i, j int) bool { return items[i].Decision.AskedAt > items[j].Decision.AskedAt })
	return items
}

func (s *Server) waitingPage(w http.ResponseWriter, r *http.Request) {
	ws := r.URL.Query().Get("ws")
	if ws != "" {
		if _, _, ok := s.service(w, r); !ok {
			return
		}
	}
	p := s.basePage(r, "Decisions", ws)
	p.Nav = "decisions"
	items := s.waitingItems(r, "")
	views := make([]decisionItem, 0, len(items))
	for _, it := range items {
		svc, err := s.opts.Backend.Service(it.Workspace)
		if err != nil {
			continue
		}
		views = append(views, newDecisionItem(svc, it.Workspace, it.Card, it.Decision))
	}
	p.Data = views
	if ws == "" {
		p.WaitingCount = len(items)
	}
	s.render(w, r, "waiting", p)
}
```

```go
type runRow struct {
	Run   store.Run
	Title string
}

type runsData struct {
	Active, Recent []runRow
	More           int // ended runs not listed
}

const recentRuns = 50

func runTouched(r store.Run) string {
	if r.UpdatedAt != "" {
		return r.UpdatedAt
	}
	return r.QueuedAt
}

func (s *Server) runsPage(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	st := svc.Store()
	runs, err := st.RunsWithStatus(store.Statuses...)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	sort.SliceStable(runs, func(i, j int) bool { return runTouched(runs[i]) > runTouched(runs[j]) })
	titles := map[string]string{}
	title := func(cardID string) string {
		if t, ok := titles[cardID]; ok {
			return t
		}
		t := cardID
		if c, err := st.Card(cardID); err == nil {
			t = c.Title
		}
		titles[cardID] = t
		return t
	}
	d := runsData{}
	for _, run := range runs {
		switch {
		case run.Active():
			d.Active = append(d.Active, runRow{Run: run, Title: title(run.CardID)})
		case len(d.Recent) < recentRuns:
			d.Recent = append(d.Recent, runRow{Run: run, Title: title(run.CardID)})
		default:
			d.More++
		}
	}
	p := s.basePage(r, "Runs", ws)
	p.Nav = "runs"
	p.Data = d
	s.render(w, r, "runs", p)
}
```

```go
package web

import (
	"net/http"
	"sort"

	"github.com/tentaqles/tentaqles/internal/hub/store"
)

func init() {
	extraRoutes = append(extraRoutes, func(s *Server) { s.handle("GET /reviews", s.reviewsPage) })
}

type reviewRow struct {
	Card     store.Card
	Run      *store.Run
	Decision *store.Decision // the pending result decision, for the waiting list
}

type reviewsData struct {
	Waiting  []reviewRow // a result decision waits on the human
	Finished []reviewRow // a finished run without a result record, card not done yet
}

func (s *Server) reviewsPage(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	st := svc.Store()
	ds, err := st.PendingDecisions()
	if err != nil {
		s.fail(w, r, err)
		return
	}
	seen := map[string]bool{}
	d := reviewsData{}
	for i := range ds {
		dec := ds[i]
		if dec.Kind != store.KindResult || seen[dec.CardID] {
			continue
		}
		card, err := st.Card(dec.CardID)
		if err != nil {
			continue
		}
		row := reviewRow{Card: card, Decision: &dec}
		if run, err := st.Run(dec.RunID); err == nil {
			row.Run = &run
		}
		seen[card.ID] = true
		d.Waiting = append(d.Waiting, row)
	}
	runs, err := st.RunsWithStatus(store.StatusFinished)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	sort.SliceStable(runs, func(i, j int) bool { return runs[i].EndedAt > runs[j].EndedAt })
	for i := range runs {
		run := runs[i]
		if seen[run.CardID] {
			continue
		}
		card, err := st.Card(run.CardID)
		if err != nil {
			continue
		}
		if lane, err := st.Lane(card.Lane); err != nil || lane.Kind == store.LaneDone {
			continue
		}
		seen[card.ID] = true
		d.Finished = append(d.Finished, reviewRow{Card: card, Run: &run})
	}
	p := s.basePage(r, "Reviews", ws)
	p.Nav = "reviews"
	p.Data = d
	s.render(w, r, "reviews", p)
}
```

```go
// Verdict is the band on top of the review page: what the gate's records say, in one line.
type Verdict struct {
	Class string // ok | wait | bad
	Title string
	Note  string
}

func (d ReviewData) Verdict() Verdict {
	passed, total, reviews := 0, 0, 0
	if d.State != nil {
		for _, c := range d.State.Checkpoints {
			total++
			if c.Status == "passed" {
				passed++
			}
		}
	}
	var dod *gate.DoDRecord
	if d.Records != nil {
		for _, rv := range d.Records.Reviews {
			if rv.Result == "PASS" {
				reviews++
			}
		}
		dod = d.Records.DoD
	}
	facts := fmt.Sprintf("%d of %d checkpoints passed, %d reviews PASS", passed, total, reviews)
	if dod != nil {
		if dod.OK {
			facts += ", DoD ok"
		} else {
			facts += ", DoD not met"
		}
	}
	facts += fmt.Sprintf(", %.0f min, $%.2f", d.Run.Seconds/60, d.Run.CostUSD)
	note := facts + ". Built from signed gate records and the hub's own git summary only; nothing here comes from what the agent said."
	switch {
	case dod != nil && !dod.OK:
		return Verdict{Class: "bad", Title: "The definition of done is not met", Note: note}
	case d.State == nil && d.Records == nil:
		return Verdict{Class: "wait", Title: "There are no gate records for this run", Note: "Read what was done before you close the card. " + d.RecordsNote}
	case total > 0 && passed == total && dod != nil:
		return Verdict{Class: "ok", Title: "Everything the gate recorded says this is done", Note: note}
	}
	return Verdict{Class: "wait", Title: "The gate's records are incomplete: read the evidence before you approve", Note: note}
}
```

```go
			l := t.Local()
			switch {
			case sameDay(l, today):
				label = "Today"
			case sameDay(l, today.AddDate(0, 0, -1)):
				label = "Yesterday"
			default:
				label = l.Format("Mon Jan 2")
			}
		}
		if len(out) == 0 || out[len(out)-1].Label != label {
			out = append(out, dayGroup{Label: label})
		}
		out[len(out)-1].Events = append(out[len(out)-1].Events, eventFor(e, title))
	}
	return out
}

func activityHref(ws, kind string, days int) string {
	v := url.Values{"ws": {ws}}
	if kind != "" {
		v.Set("kind", kind)
	}
	if days != 1 {
		v.Set("days", strconv.Itoa(days))
	}
	return "/activity?" + v.Encode()
}

func (s *Server) activityPage(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	q := r.URL.Query()
	kind := q.Get("kind")
	if _, known := activityKinds[kind]; !known {
		kind = ""
	}
	days, _ := strconv.Atoi(q.Get("days"))
	if days != 7 && days != 30 {
		days = 1
	}
	at := now()
	es, err := svc.Store().ActivitySince(windowStart(days, at), activityLimit)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	d := activityData{Stats: summarize(es), Truncated: len(es) == activityLimit}
	for _, k := range kindFilters {
		d.Kinds = append(d.Kinds, filterLink{Label: k.Label, Href: activityHref(ws, k.Key, days), On: k.Key == kind})
	}
	for _, p := range periodFilters {
		d.Periods = append(d.Periods, filterLink{Label: p.Label, Href: activityHref(ws, kind, p.Days), On: p.Days == days})
	}
	shown := es
	if kind != "" {
		shown = nil
		for _, e := range es {
			if slices.Contains(activityKinds[kind], e.Verb) {
				shown = append(shown, e)
			}
		}
	}
	titles := map[string]string{}
	title := func(id string) string {
		if id == "" {
			return ""
		}
		if t, ok := titles[id]; ok {
			return t
		}
		t := id
		if c, err := svc.Store().Card(id); err == nil {
			t = c.Title
		}
		titles[id] = t
		return t
	}
	d.Days = groupByDay(shown, title, at)
	p := s.basePage(r, "Activity", ws)
	p.Nav = "activity"
	p.Data = d
	s.render(w, r, "activity", p)
}
```

```go
var numberNoise = strings.NewReplacer(",", "", "_", "", " ", "", "$", "")

// settingsFromForm turns the form's text into typed values; a blank field keeps cur. Nothing the
// form sent is stored as text: the runner validates the numbers and the store re-serialises them.
func settingsFromForm(r *http.Request, cur runner.Settings) (runner.SettingsUpdate, error) {
	var u runner.SettingsUpdate
	field := func(k string) (string, bool) {
		v := numberNoise.Replace(strings.TrimSpace(r.PostFormValue(k)))
		return v, v != ""
	}
	if v, ok := field("concurrency"); ok {
		n, err := strconv.Atoi(v)
		if err != nil {
			return u, fmt.Errorf("concurrency: want a whole number from 1 to 16")
		}
		u.Concurrency = &n
	}
	b, touched := cur.DefaultBudget, false
	if v, ok := field("usd"); ok {
		f, err := strconv.ParseFloat(v, 64)
		if err != nil {
			return u, fmt.Errorf("dollars: want a number, such as 15 or 7.50")
		}
		b.USD, touched = f, true
	}
	if v, ok := field("tokens"); ok {
		n, err := strconv.ParseInt(v, 10, 64)
		if err != nil {
			return u, fmt.Errorf("tokens: want a whole number, such as 2,000,000")
		}
		b.Tokens, touched = n, true
	}
	if v, ok := field("minutes"); ok {
		f, err := strconv.ParseFloat(v, 64)
		if err != nil {
			return u, fmt.Errorf("minutes: want a number")
		}
		b.Minutes, touched = f, true
	}
	if v, ok := field("rounds"); ok {
		n, err := strconv.Atoi(v)
		if err != nil {
			return u, fmt.Errorf("rounds: want a whole number")
		}
		b.Rounds, touched = n, true
	}
	if touched {
		u.DefaultBudget = &b
	}
	switch strings.TrimSpace(r.PostFormValue("notify")) {
	case "on":
		on := true
		u.Notify = &on
	case "off":
		off := false
		u.Notify = &off
	case "":
	default:
		return u, fmt.Errorf("notifications: use on or off")
	}
	return u, nil
}

func (s *Server) formSettings(w http.ResponseWriter, r *http.Request) {
	svc, ws, ok := s.service(w, r)
	if !ok {
		return
	}
	u, err := settingsFromForm(r, svc.Settings())
	if err != nil {
		s.fail(w, r, err)
		return
	}
	if _, err := svc.UpdateSettings(s.reqCtx(r), u); err != nil {
		s.fail(w, r, err)
		return
	}
	s.redirect(w, r, "/settings?ws="+url.QueryEscape(ws)+"&flash=settings-saved")
}

func (s *Server) apiSettings(w http.ResponseWriter, r *http.Request) {
	svc, _, ok := s.service(w, r)
	if !ok {
		return
	}
	writeJSON(w, 200, svc.Settings())
}

func (s *Server) apiUpdateSettings(w http.ResponseWriter, r *http.Request) {
	svc, _, ok := s.service(w, r)
	if !ok {
		return
	}
	var u runner.SettingsUpdate
	if err := decode(r, &u); err != nil {
		s.fail(w, r, err)
		return
	}
	got, err := svc.UpdateSettings(s.reqCtx(r), u)
	if err != nil {
		s.fail(w, r, err)
		return
	}
	writeJSON(w, 200, got)
}
```

```go
// TestEveryPageHasTheShellAndIsCSPSafe walks every GET page: the shell is there, exactly one nav
// entry is current, no inline script or handler slipped in, and ?fragment=main renders only #main.
func TestEveryPageHasTheShellAndIsCSPSafe(t *testing.T) {
	e := newEnv(t, "acme")
	svc := e.svcs["acme"]
	c, _ := svc.Add(context.Background(), store.NewCard{Title: "Sweep", Tags: []string{store.TagAgentReady}}, nil)
	r, _ := e.pendingDecision("acme", c, store.KindResult)
	svc.Comment(context.Background(), c.ID, "a comment")
	ts := e.server(Options{Bind: "127.0.0.1:7470"})
	pages := []string{
		"/?ws=acme", "/cards/" + c.ID + "?ws=acme", "/cards/" + c.ID + "/review?ws=acme", "/waiting?ws=acme",
		"/runs?ws=acme", "/runs/" + r.ID + "?ws=acme", "/reviews?ws=acme", "/activity?ws=acme",
		"/activity?ws=acme&kind=runs&days=7", "/connections?ws=acme", "/settings?ws=acme",
	}
	for _, path := range pages {
		code, body, hdr := get(t, ts, path, nil)
		if code != 200 {
			t.Errorf("%s: %d", path, code)
			continue
		}
		for _, want := range []string{`<aside class="side">`, `id="themebtn"`, `<symbol id="i-sun"`, `id="new-card"`, `<script src="/static/hub.js"></script>`, `id="toast"`} {
			if !strings.Contains(body, want) {
				t.Errorf("%s lacks %q", path, want)
			}
		}
		if n := strings.Count(body, `aria-current="page"`); n != 1 {
			t.Errorf("%s: %d current nav entries", path, n)
		}
		if !strings.Contains(hdr.Get("Content-Security-Policy"), "script-src 'self'") {
			t.Errorf("%s: CSP %q", path, hdr.Get("Content-Security-Policy"))
		}
		assertCSPSafe(t, path, body)
		sep := "&"
		if !strings.Contains(path, "?") {
			sep = "?"
		}
		_, frag, _ := get(t, ts, path+sep+"fragment=main", nil)
		if strings.Contains(frag, `class="side"`) || strings.Contains(frag, "<html") || strings.Contains(frag, `id="new-card"`) {
			t.Errorf("%s: fragment=main carries more than #main", path)
		}
	}
	_, all, _ := get(t, ts, "/waiting", nil)
	assertCSPSafe(t, "/waiting", all)
}

// TestNewRoutesRefuseAnUnavailableWorkspace: every route this redesign added answers 403 for a
// listed but unavailable workspace and never opens it.
func TestNewRoutesRefuseAnUnavailableWorkspace(t *testing.T) {
	e := newEnv(t, "acme")
	b := e.backend()
	b.Infos = append(b.Infos, WorkspaceInfo{Name: "zeta", Available: false, Reason: "untrusted"})

		}

	}

// TestNewWritesNeedSameOrigin: the new form routes sit behind the same guard as the old ones.

		}

	}
```
