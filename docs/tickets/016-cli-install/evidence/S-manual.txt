$ tentaqles install --help
Install the CLI of a provider in this identity's scope. The catalog's install methods are tried in
the order winget, scoop, brew, apt, npm, pip, and the first whose package manager is on the PATH
runs (ten minutes at most, then it is stopped). A provider that already resolves on the identity
PATH runs nothing. A desktop installer is never run by tq: with no usable method the line says
where to download it. A provider outside the identity's scope is refused and logged.
Takes the provider id and nothing else.

Usage:
  tentaqles install <provider> [flags]

Examples:
  tentaqles install az

Flags:
  -h, --help   help for install
exit code: 0
