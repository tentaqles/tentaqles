$ go run ./cmd/tq --help
Tentaqles: one terminal identity per workspace folder

Usage:
  tentaqles [command]

Available Commands:
  activate    Print the hook to add to your shell profile, e.g. eval "$(tq activate bash)"
  allow       Trust a workspace's current manifest so it can export env (human only)
  bundle      Manage Claude bundles (plugins, skills, MCP servers) from a shared catalog
  claude-hook Claude Code hook adapter (reads the hook JSON on stdin)
  completion  Generate the autocompletion script for the specified shell
  connect     Register a provider's MCP server (from the catalog) in this client's Claude config
  deny        Revoke trust for a workspace (human only)
  doctor      Verify hooks, trust, git and env against the manifests (never mutates)
  dotenv      Use a .env file without printing its values
exit code: 0
